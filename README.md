# CS 210 Programming Languages
## Airgead Banking Project

### Summarize the project and what problem it was solving.
For this project, I created an investment calculator for Airgead Banking. The program allows the user to enter an initial investment amount, monthly deposit, annual interest rate, and number of years. It then calculates and displays how the investment grows over time with and without additional monthly deposits. The purpose of the program was to help users understand how saving money and compound interest can affect their investments over time.

### What did you do particularly well?
I think I did well with organizing the program and displaying the results in a way that is easy for the user to understand. I also separated different parts of the program into functions instead of putting everything inside `main()`. This helped keep the code organized and made it easier to understand what each part of the program was doing.

### Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?
One area I could improve is input validation. The program could do a better job of checking for incorrect input, such as negative numbers or letters being entered where numbers are expected. Adding stronger input validation would make the program more reliable and prevent errors caused by invalid user input. I could also simplify some parts of the code to make it more efficient and easier to update.

### Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?
The most challenging part for me was working with the calculations and making sure the interest and monthly deposits were calculated correctly. Formatting the output was also challenging because I had to make sure the information lined up and was easy to read. I overcame these problems by testing different parts of the program, reviewing examples from the course, and fixing errors as I found them. Course resources, documentation, and programming examples are resources I can continue using when I get stuck.

### What skills from this project will be particularly transferable to other projects or course work?
Some of the most transferable skills I learned were using classes and functions, organizing code into separate files, working with calculations, formatting output, and debugging errors. I also gained more experience with C++ and learned how breaking a larger problem into smaller pieces can make a program easier to build. These skills will be useful in future programming courses and larger software development projects.

### How did you make this program maintainable, readable, and adaptable?
I made the program maintainable and readable by separating different responsibilities into functions and using descriptive names for variables and methods. I also used comments to explain important sections of the program. Keeping the code organized makes it easier to find problems and make changes later. The program can also be adapted because the investment calculations are separated from the main part of the program instead of having all of the logic in one place.
